# CampusFace Attendance

A lecturer-only university attendance management web application with a separately installable Android APK.

## Access model

- Only authorised lecturers and administrators may sign in.
- Students do not have accounts, login pages, dashboards, or self-registration.
- Lecturers manage student records, course enrolments, attendance sessions, and reports.

## Current development status

- Task 1: React, TypeScript, Vite and repository foundation.
- Task 2: responsive lecturer web interface, appearance settings, and Android download button.
- Android packaging: Capacitor Android project is generated by GitHub Actions; the APK is published to a GitHub Release.
- The visible interface is still a preview. Authentication, database writes, real student records, camera capture and attendance processing are not connected yet.

## Main application areas

The two main workspace tabs are **Registration** and **Attendance**. Academic settings and staff permissions are grouped under a restricted settings menu and will require administrator access.

## Technology

- React + TypeScript + Vite for the web interface.
- Capacitor 8 for the native Android application container.
- Android APK includes the built web interface locally inside the app; it does not install a browser shortcut.
- Supabase is planned for authentication, database and server-side access policies (not configured yet).
- Browser/device features will be connected through native Capacitor plugins where needed.

## Local web development

Requirements: Node.js 22+ and npm.

```bash
npm install
npm run dev
```

Build and typecheck:

```bash
npm run build
```

## Android APK

The repository workflow **Build Android APK** runs on pushes to `main` and on manual dispatch. It builds the web app, generates the Android project with Capacitor, builds an installable Android APK, and attaches it to a GitHub Release.

Download the latest APK:

`https://github.com/henrymeraldcompany-bit/campusface-attendance/releases/latest/download/CampusFace-Attendance.apk`

On Android, download the APK, open it from Downloads, and follow Android's app-install confirmation. Android may require you to allow the browser or file manager to install apps from that source. The APK can be shared with another Android device.

The initial automated package is a debug-signed APK for direct testing and distribution. Before Play Store publication or long-term update distribution, create a private release-signing key and store it in GitHub Actions secrets. Do not publish the signing key.

## Website deployment

The web application is published at:

`https://henrymeraldcompany-bit.github.io/campusface-attendance/`

GitHub Pages deploys the normal website. The separate Android build workflow produces the APK.

## Privacy and safety

Biometric information is sensitive personal data. Do not commit student records, face images, biometric templates, credentials, API keys or real attendance data to this repository. Before any real deployment, obtain institutional approval, establish a lawful basis and appropriate consent process, complete a privacy impact assessment, define retention and deletion rules, and test security and recognition accuracy. Uncertain face matches must be referred for human verification rather than automatically recorded.
